1. Shell 语法、`docker compose config --quiet` 和 `git diff --check` 通过。
2. 最终 `0001` dry-run 成功并回滚，关系数保持 `0`；随后在新空库执行正式迁移和 `verify-0001.sql`，43 张 V1 表及 `UNIQUE(account_id, idempotency_key_hash)` 均通过。
