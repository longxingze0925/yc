# P0 本地开发说明

文档状态：历史开发记录，仅说明 P0 骨架现状，不作为当前冻结开发规格。新的产品、架构、协议、客户端、服务端和测试实现必须以 README 文档入口中的冻结文档为准。

## 目标

当前工程骨架使用 Rust workspace 管理核心库和服务端空服务。P0 阶段不引入网络依赖，保证后续拿到 Rust 工具链后可以离线构建和测试。

## 模块

```text
crates/remote-protocol
  协议消息、错误码、消息头编解码

crates/remote-core
  设备身份、会话状态机、权限策略

crates/remote-transport
  连接路径、候选链路、传输抽象

crates/remote-crypto
  密钥和会话密钥类型，占位集成平台加密实现

crates/remote-capture
  Windows/Ubuntu 屏幕采集抽象

crates/remote-render
  Windows/Ubuntu/iOS 渲染抽象

services/api-server
  P0 HTTP 健康检查空服务

services/signal-server
  P1 HTTP + WebSocket 信令服务，当前支持设备注册和在线状态

services/relay-server
  P0 Relay 空服务
```

## 本地命令

项目根目录提供 `rust-toolchain.toml`，默认使用 `stable`、`minimal` profile，并安装 `rustfmt` 和 `clippy` 组件。

安装 Rust 工具链后执行：

```bash
make fmt-check
make lint
make test
make check
```

如果使用 Ubuntu apt 安装 Rust，`cargo-fmt` 和 `cargo-clippy` 可能位于 `/usr/lib/rust-1.93/bin`，项目 `Makefile` 已按这个路径做默认兼容。

启动空服务：

```bash
cargo run -p api-server
cargo run -p signal-server
cargo run -p relay-server
```

默认监听：

```text
api-server: 127.0.0.1:18080
signal-server: 127.0.0.1:18081
relay-server: 127.0.0.1:18082
```

可通过环境变量覆盖：

```text
REMOTE_API_BIND
REMOTE_SIGNAL_BIND
REMOTE_RELAY_BIND
```
